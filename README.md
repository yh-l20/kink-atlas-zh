# 偏好图谱 · Kink Atlas 中文版

中文偏好探索、个人分析与两人对照。静态网站，所有问卷答案都在浏览器本地处理。

- 网站：https://yh-l20.github.io/kink-atlas-zh/
- 原始参考：https://app.kinkchecklist.com/try
- 120项精选中文改编，以及完整518条原站中文目录（2026-10-02读取）。保留英文名便于核对；合并思路用于精选目录，完整目录保留重复项。
- 完整目录445条可评估；73条涉及无法同意的对象、非自愿表述或高风险内容，只保留说明，不进入评分或对照。

## 分析方法

每类已明确回答按不愿意0、有点好奇50、喜欢75、很喜欢100取平均。不确定和缺失不计分，至少3项有效回答才给初步解释，始终显示分母。没有人格诊断、能力判断或伴侣匹配率。

对照顺序：任一拒绝 → 缺少回答 → 不确定 → 仅限想象 → 同角色需协调 → 双方明确喜欢且都愿意讨论尝试 → 其他待沟通兴趣。喜欢及愿意讨论均不等于当下行为同意。

两套目录使用独立题目ID、分别统计，双方对照应选择同一套目录。原站重复条目可能影响平均，具体回答比平均值更重要。

## 隐私

默认只保留在当前页面，勾选后才保存到localStorage。对方文件仅在页面内存中处理。分享网站链接不带任何回答。导出JSON包含全部具体回答、角色及意愿，未经加密；仅向你信任的人自愿分享。没有第三方脚本、远程API请求或答案上传。GitHub可能记录常规网页访问日志。

## 本地运行与测试

需要Node.js（仅运行测试）和Python（本地服务器）。

```sh
npm test
npm start
```

打开 http://127.0.0.1:4173/ 。没有依赖安装步骤，也没有构建步骤。GitHub Pages从main根目录发布，所有资源使用相对路径。

## 文件

`data.mjs` 精选内容；`catalog.mjs` 原站目录中文改编；`engine.mjs` 分析与文件验证；`app.mjs` 交互；`styles.css` 响应式样式；`tests/engine.test.mjs` 核心规则测试。

独立改编，与原站无隶属关系。不复用原站商标、图片或应用代码。原文采用中性中文说明重新表述；目录和概念来源见上方链接。面向自愿成年人，用于自我了解与沟通，不提供高风险活动操作指导。
